# TingShuo 2.0.0 beta 1

The first v2 beta improves study content, sentence practice, save reliability,
and appearance while retaining existing learning progress from the v1 betas.

## Changes

- Full bundled-content review: improved 197 study definitions and corrected 357
  primary example records, including Chinese, translations, and contextual pinyin.
- Sentence practice uses source pinyin and reviewed word associations to avoid
  offering a different reading or an unrelated word fragment for rating.
- **Another sentence** offers up to five complete examples per word, including
  1,611 Tatoeba alternates for 833 words. Source readings, IDs, and credit remain.
- Sentence listening reuses 3,567 unique attributed Tatoeba transcripts.
- Vocab Rush retains answers until saved, with persistent retries and guarded
  advancement, results, and navigation. Queue retries preserve the original date
  and do not repeat an already committed review.
- Nine appearance palettes, including the new Sakura, Jade, Copper, and Slate.
- Improved large-text handling for the bilingual Vocab Rush Start/Play Again button.

## Upgrading

Use the same app package and Android signing identity as previous releases.
The major-version label does not reset study data. Bundled content corrections
update shared cards in place while preserving IDs, reviews, progress, resumable
sessions, and custom content. Export a study backup in Settings before upgrading.

Android version name: `2.0.0-beta.1`; version code: `9`.

## Beta scope

Core study works offline without an account or AI provider. Optional AI features
use your own key. macOS packages are ad-hoc signed without Developer ID signing
or notarization; Windows packages are unsigned portable bundles. Native speech,
keychain, file pickers, and upgrade flows still need target-device testing.

Vocab Rush guards normal navigation and cancellable app-close requests while an
answer is unsaved. It has no persisted outbox; forced termination or power loss
can lose an answer that has not committed. Chats, exam results, and listening
scores remain in memory; explicit vocabulary assessments are saved.
